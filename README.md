# Kanika-s-Portfolio

A modern, responsive personal portfolio website built with React.js and Tailwind CSS, showcasing my projects, skills, experience, and achievements.

Live Demo
(https://kanika-goyal.netlify.app)

Built With
- React.js
- Tailwind CSS
- Vite
- Formspree (contact form)
- Netlify (deployment)

Sections
- Hero — Introduction with social links and resume download
- About — Bio, quick facts, and academic stats
- Experience — Club roles and leadership activities
- Skills — Tech stack organized by category
- Projects — FloraNourish, Sales Dashboard, Portfolio
- Education — Academic timeline
- Certifications — NPTEL, Cisco, AWS
- Achievements — Awards and extracurriculars
- Contact — Working contact form
